# Auditorium and living lock artwork

Created with built-in image generation. Original transparent PNGs and optimized WebP game assets are saved together in this directory, using the stems `fuzzy-lock-v1`, `slug-lock-v1`, `jelly-lock-v1`, `spark-butterfly-v1`, and `auditorium-backdrop-v1`.

The user's caterpillar reference informed the fuzzy creature. The other creatures have independently generated silhouettes and materials. Game digits are real HTML controls; none of the numbers are baked into the illustrations.

The stage is a projected illustrated back wall, with additional projected side windows and procedural floorboards. Characters remain separate, animated 2.5D billboards.
